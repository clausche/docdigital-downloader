Flujo de descarga de DocDigital

El descargador no inicia sesión ni amplía permisos: automatiza descargas que DocDigital autoriza previamente para la sesión oficial del usuario.

1 Autenticación oficial
🌐 El usuario abre DocDigital Desde un navegador con acceso a Internet
🔐 Inicia sesión oficialmente ClaveÚnica / mecanismo oficial de DocDigital
🎟️ DocDigital crea la sesión El servidor entrega un token temporal
🧩 La extensión muestra su panel Sólo dentro de los dominios de DocDigital
2 Inicio y control de sesión
DECISIÓN ¿Existe un token de sesión oficial activo? La extensión no puede crear ni reemplazar este token.
No
⛔ El proceso se detiene Solicita iniciar sesión en DocDigital
Sí
📁 El usuario elige una carpeta Luego pulsa «iniciar descarga»
3 Consulta y autorización de documentos
📋 Consulta las bandejas Solicitudes GET con el token oficial
SERVIDOR DocDigital valida sesión y permisos El applet no toma esta decisión
✅ Entrega documentos autorizados Sólo los visibles para ese usuario
401 · Sesión vencida La descarga se detiene.
403 · Sin permiso Se omite el documento o la bandeja.
Restringido o no disponible Se registra, pero no se descarga.
4 Descarga y guardado

Chrome · acceso directo a carpeta

Descarga autorizada Principal, anexo o trazabilidad
El navegador escribe el archivo Mediante la API de acceso a carpetas

Brave · ayudante local

La extensión valida la solicitud Origen, URL, categoría y nombre
El ayudante vuelve a validar Token, URL y ruta de destino
Guarda el archivo localmente Dentro de la carpeta elegida
5 Repetición y resultado
🔁 Repite el proceso Documentos, anexos, trazabilidad y bandejas
📊 Cuenta los resultados Nuevos, existentes, no disponibles y errores
🏁 Muestra el resumen final El token no se almacena como archivo
Idea central: sin ingreso oficial no existe token; sin token el applet se detiene. DocDigital conserva la decisión final sobre qué documento puede descargar cada usuario.
Flujo construido a partir de docdigital-downloader.js, background.js y native_host.py.
